# Moments Together

> 翻一張，靠近一點。

Moments Together 是一個適合家人、朋友或混合聚會使用的對話式翻牌遊戲。
玩家輪流翻牌、回答問題或完成小任務，其他人依照牌面加入互動。

## 功能

- 家人、朋友與混合模式
- 2–8 位成員設定
- 輪流指定翻牌玩家
- 12 張對話與任務卡
- 六種卡片類別
- 跳過與收藏
- 正向引導語
- 瀏覽器本機保存設定與收藏
- 手機優先響應式介面

## 本機預覽

這是一個無須安裝套件的單頁網站。

直接開啟 `index.html` 即可使用。部分瀏覽器對本機儲存的限制不同，建議也可以使用任何靜態網站伺服器預覽。

## 發布至 GitHub Pages

1. 建立新的 GitHub repository。
2. 將本資料夾內所有檔案放在 repository 根目錄。
3. 推送至 `main` branch。
4. 前往 repository 的 `Settings → Pages`。
5. 在 `Build and deployment` 選擇 `Deploy from a branch`。
6. 選擇 `main` 與 `/ (root)` 後儲存。

GitHub 完成發布後，網站會出現在：

`https://你的帳號.github.io/你的-repository-名稱/`

## 技術

使用原生 HTML、CSS 與 JavaScript 製作，沒有外部套件、追蹤程式或後端服務。

目前成員資料與收藏只會保存在使用者自己的瀏覽器。
